Development Workflow
═══════════════════════════════════════════════════════════════════

1. npm install
   └─ Installs all dependencies from package.json

2. npm run dev
   └─ Starts dev server with HMR at localhost:5173
   
3. Edit files
   └─ Changes auto-reload in browser (HMR)

4. npm run build
   └─ Creates optimized production build in dist/

5. npm run preview
   └─ Previews production build locally

Tips for Navigation
═══════════════════════════════════════════════════════════════════

To understand the project:
  1. Start with README.md (overview)
  2. Read QUICK_START.md (setup)
  3. Study ARCHITECTURE.md (design)
  4. Reference COMPONENTS.md (details)

To modify something:
  1. Check src/types/index.ts for data structure
  2. Look at src/data/mockData.ts for sample data
  3. Find the component in src/components/
  4. Edit and save (auto-refresh)

To add a feature:
  1. Define types in src/types/index.ts
  2. Add mock data in src/data/mockData.ts
  3. Create component in src/components/[domain]/
  4. Import in App.tsx
  5. Add to JSX rendering logic
